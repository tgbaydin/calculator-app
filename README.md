# Sunny — Full-Stack Calculator

A responsive calculator built with **React + TypeScript** and a **Go REST API**. The interface uses a warm orange, yellow and cream palette. All arithmetic is performed by the Go backend; the frontend sends JSON requests and displays the returned result.

## Features

- Addition, subtraction, multiplication and division
- Power, square root and percentage (`a × b / 100`)
- Input validation and clear API error messages
- Division-by-zero and negative-square-root protection
- Recent calculation history (session-only)
- Keyboard shortcuts: `Enter` calculates, `Esc` clears
- Responsive desktop and mobile layout
- Unit tests for Go calculation/API behavior and the frontend API client

## Requirements

- Go 1.22+

## Run locally

### 1. Start the backend

```bash
cd backend
go run .
```

The API listens on `http://localhost:8080`.

### 2. Start the frontend

In a second terminal:

```bash
cd frontend
npm install
npm run dev
```

Open the Vite URL printed in the terminal (normally `http://localhost:5173`). The frontend defaults to `http://localhost:8080` for the API. To use another API URL, create `frontend/.env`:

```env
VITE_API_URL=http://localhost:8080
```

## REST API

All calculation endpoints accept `POST` with a JSON body and return JSON.

| Method | Endpoint | Meaning |
|---|---|---|
| GET | `/api/health` | Health check |
| POST | `/api/calculate/add` | Addition |
| POST | `/api/calculate/subtract` | Subtraction |
| POST | `/api/calculate/multiply` | Multiplication |
| POST | `/api/calculate/divide` | Division |
| POST | `/api/calculate/power` | Exponentiation (`a` to the power of `b`) |
| POST | `/api/calculate/sqrt` | Square root of `a` |
| POST | `/api/calculate/percent` | `a` percent of `b` (`a × b / 100`) |

Example:

```bash
curl -X POST http://localhost:8080/api/calculate/add \
  -H 'Content-Type: application/json' \
  -d '{"a": 12, "b": 8}'
```

Success response (`200 OK`):

```json
{"operation":"add","result":20}
```

Validation error (`400 Bad Request`):

```json
{"error":"division by zero is not allowed"}
```

The API returns `405 Method Not Allowed` for non-POST calculation requests. Inputs must be finite JSON numbers. Unknown operations return a client error.

## Design decisions

- **Thin frontend / calculation service:** the React app owns input state, validation feedback and presentation. The Go API is the source of truth for arithmetic results.
- **One endpoint per operation:** `/api/calculate/{operation}` keeps the API explicit and easy to extend.
- **Consistent JSON contract:** success responses contain `operation` and `result`; failures contain an `error` message.
- **Defensive backend validation:** malformed JSON, unsupported operations, division by zero, negative square roots and non-finite results are rejected.
- **Testable calculation core:** arithmetic is isolated in a pure `calculate` function, separately testable from HTTP handling.
- **Simple deployment:** no database is needed for a calculator; recent history is intentionally kept in frontend session state.

## Assumptions

- Percentage is interpreted as “what is `a` percent of `b`?” (`a × b / 100`).
- Square root is unary and uses only `a`.
- Recent activity is temporary and resets when the page is refreshed.
- CORS is permissive for this small assessment/demo. A production deployment should restrict allowed origins.
